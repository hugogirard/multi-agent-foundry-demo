Infrastructure Pipeline Architecture

GitHub Actions workflow — infra.yaml — provisions all Azure resources for the Multi-Agent Foundry Demo

Trigger

workflow_dispatch

Manual trigger from the Actions tab with configurable inputs

job_to_run: all | delete-app-registration | create-azure-resources | update-mcp-foundry-connection | grant-admin-consent bring_your_own_resource: true | false
Cleanup

delete-app-registration

Remove existing Entra ID app registrations to ensure a clean deployment slate, then wait 120 seconds for propagation across Azure AD

Azure Login delete-app-registrations.sh Wait 120s
needs: delete-app-registration
Deployment

create-azure-resources

Deploy infra/main.bicep at subscription scope (Sweden Central), capture all deployment outputs, and persist them as GitHub repository secrets

Resource Group Foundry + Project Container Registry Web Apps (MCP + API) VNET Cosmos DB App Insights Client IDs → Secrets
Post-Provision

update-mcp-foundry-connection

Wire up the Foundry MCP connection after deployment

Generate client secret Create MCP connection Patch OAuth redirect URI
Post-Provision

grant-admin-consent

Grant admin consent for all MCP server app registrations

Flight MCP Server Foundry Connection
Clean Entra
Deploy Bicep
Wire Foundry
Grant Consent
