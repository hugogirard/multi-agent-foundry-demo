Shared Steps

Each Job Follows the Same Pattern

1 Azure Login with service principal credentials
2 Build Docker image from source directory & push to Azure Container Registry
3 Generate Entra ID app secret via Microsoft Graph API (with retry logic)
4 Inject app settings (client IDs, secrets, endpoints) into App Service
5 Deploy container image to Azure App Service
