Load Data Pipeline

GitHub Actions workflow — load_data.yaml — seeds Cosmos DB with sample flight & hotel data

Trigger

workflow_dispatch

Manual trigger from the Actions tab — no inputs required

Reads COSMOS_DB_NAME from secrets Reads AZURE_RESOURCE_GROUP from secrets
Setup

Python 3.11 + uv

Check out repo, install Python runtime and uv package manager, then install dependencies from utility/pyproject.toml

actions/checkout actions/setup-python uv pip install azure-cosmos
Authenticate

Azure Login + Connection String

Authenticate with AZURE_CREDENTIALS and retrieve the Cosmos DB primary connection string via az cosmosdb keys list

azure/login@v2 az cosmosdb keys list --type connection-strings
Source Data

data/flights.json

24 flights — Montreal & Toronto → 8 European cities

YUL → 8 destinations YYZ → 3 destinations Prices in CAD
Source Data

data/hotels.json

30 hotels — 3 per city across 10 cities

3–5 star ratings 10 cities Amenities + policies
Processing

utility/data_loader.py

Processes both JSON files through three idempotent steps

1. Delete existing items 2. Shift flight dates (+3 weeks) 3. Assign UUIDs & insert
